# chore: Standardize on the repo-ci-baseline Template

- **Release tag:** `v0.0.1`
- **Source PR:** [#5](https://github.com/mpaulosky/SuggestionApp/pull/5)

## PR description

### Why

SuggestionApp joins the Baseline (mpaulosky/dotfiles#129): the same hooks, CI, release pipeline, auto-merge and GitHub settings as the other repos. It had no CI on `main`; the squad workflows it once had were never committed.

### What changed

- **Solution:** `SuggestionApp.sln` → `SuggestionApp.slnx`, which the gate, CI and `apply.sh` build.
- **Apply:** `chore: apply repo-ci-baseline Template` is `apply.sh`'s output alone, from the Template at mpaulosky/dotfiles@f4848e8.
- **Adapt:**
  - Dependabot takes the Seed's config, adding the .NET SDK ecosystem and conventional commit prefixes (no Testcontainers group: there are no tests).
  - The old `.github/codecov.yml` goes; the root `codecov.yml` is the one Codecov reads.
  - Markdown brought to the Baseline's rules: 342 issues to 0, wording unchanged. The vendored open-iconic README is left unlinted.
  - Nullable warnings fixed rather than suppressed, since the Baseline builds with `-warnaserror`. Fields a page loads after its first render are nullable, as the markup already treats them. This also fixes three crashes: Index's and Details' status checks used a non-short-circuit `|`, Profile read the user's id before its null check, and Index called `.Equals` on identity claims that may be missing.

### Verification

- `scripts/gate.sh` passed, locally and in the pre-push gate: Markdown, YAML, workflow and shell lint, then a Release build with `-warnaserror` (0 warnings). There are no test projects, so the test step skips.
- The nullable changes were checked by the build and by reading the diff only, since the repo has no tests. A manual pass over Index, Details, Create, Profile and Admin Approval is worth doing before merging.
- Landing follows the skill: draft while `github-settings.sh --fix` runs and the docs-only probe runs, then a hand merge.
